02 — what actually broke

The part tutorials skip

The interesting work wasn't writing the workflow file. It was making every piece talk to the next one — and fixing it when they didn't.

deploy failed
First run didn't completeWorkflow triggered fine, but the deploy step exited before finishing.
permissions
Linux file permissions blocked the writeThe runner user couldn't write into nginx's serving directory.
runner down
Self-hosted runner needed a restartIt stopped listening for new jobs and had to be brought back manually.
nginx config
Server block wasn't pointing at the right rootSmall config fix — but it's the difference between 404 and a live page.
resolved
Job deploy / build completed with result: SucceededEvery fix here taught a bigger lesson than the tutorial did.
