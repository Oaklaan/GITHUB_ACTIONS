🚀 GitHub to AWS EC2 Deployment

Simple demonstration of hosting a website using GitHub and an EC2 instance

💻 Local Machine

Write website code

→

🐙 GitHub

Push source code

→

⚙️ GitHub Runner

Run deployment commands

→

☁️ AWS EC2

Host the website

📋 Deployment Steps

1

Create the Website

Create your HTML, CSS and JavaScript files on your local computer.

index.html
2

Push Code to GitHub

Initialize Git and push your project to a GitHub repository.

git init
git add .
git commit -m "Initial website"
git push origin main
3

Configure GitHub Runner

A GitHub Actions self-hosted runner can execute deployment commands on your infrastructure.

GitHub Repository
↓
GitHub Actions
↓
Self-Hosted Runner
4

Prepare AWS EC2

Launch an EC2 instance and install a web server such as Apache or Nginx.

sudo apt update
sudo apt install nginx -y
5

Deploy Website to EC2

Copy the website files to the web server directory.

sudo cp index.html /var/www/html/
6

Access the Website

Open your EC2 public IPv4 address in a web browser.

http://YOUR-EC2-PUBLIC-IP

🎉 Website Successfully Hosted!
